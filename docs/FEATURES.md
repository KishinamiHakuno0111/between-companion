# 聊天功能与官方 API 对照

核对日期：2026-11-17。此间 0.3.0 的电脑和安卓版本共用聊天逻辑。

| 常用功能 | 此间中的入口与行为 |
| --- | --- |
| 当前日期、时间与时区 | 每轮从运行设备读取时间，使用浏览器/手机的时区；作为本轮环境信息注入一次，不保存成聊天消息，不参与历史摘要。 |
| 联网搜索 | 输入框上方「联网搜索」，默认关闭。开启后由模型判断何时搜索；显示搜索状态、正文引用标记和可展开的来源链接。 |
| 阅读链接 | 「工具设置 → 阅读消息中的链接」，默认开启。把网页链接发在消息里即可；网页阅读记录按角色保存，支持后续追问。 |
| 深度思考、思考强度 | 输入框上方「深度思考」，默认开启；工具设置可选轻度、标准、深入。思考过程可折叠查看，开启联网时也支持深度搜索。 |
| 语音输入 | 「语音输入 → 结束录音」，最长 120 秒；经 DeepSeek 转写后放入输入框，由你检查并发送。首次使用按系统提示授予麦克风权限。 |
| 朗读回答 | 回复下方「朗读」，可停止；工具设置可选海星女声、暗潮男声。长回复自动分段朗读。 |
| 图片与文档 | 附件按钮、拖入、粘贴；图片、PDF、Office 等仍按原有模型能力处理。 |
| 模型选择、流式回复 | 填 Key 后连接获取模型，下拉选择；回复逐字显示，可停止，失败可重试或编辑后重试。 |
| 复制回答 | 回复下方「复制」。 |

联网搜索与阅读链接使用 **DeepSeek 官方 `deepseek-flash`**。思考模式和语音使用 DeepSeek 官方接口；通用 OpenAI 兼容服务不会收到 DeepSeek 专用的工具参数。当前时间对两类服务都生效。

搜索、网页抓取、语音识别、语音合成由 DeepSeek 按用量计费。未开启联网搜索不会发起新搜索；阅读链接是独立开关。录音只用于转写，不保存到聊天数据库。语音播放由用户主动点击，不自动朗读。

## 上下文与来源

- 新一轮重新读取当前时间。重试也使用新的时间，不复用上一轮的环境提示。
- 网页工具响应、阅读签名、引用与思考结果保存在对应角色的回复元数据中；兼容的 DeepSeek 请求按官方格式回传，换服务或模型不会发送不匹配的扩展字段。
- 来源分为「引用来源」与「查阅网页」；只有服务商明确标记的引用才显示正文角标。链接仅允许 HTTP/HTTPS，文字按纯文本转义。
- 历史摘要只读取真实用户/助手对话及原有附件，不重复压缩当前时间、人设、长期记忆或工具内部信息。工具元数据计入保守的上下文大小估算；较早对话被摘要覆盖后不再重复发送其网页签名。
- 搜索结果和网页内容仍受服务商权限、网络与可访问性影响。搜索开关允许模型调用工具，并不强迫每条闲聊都上网。

## 本次核对范围

已对照官方 Chatbot 功能表补齐日期、搜索、阅读链接、思考控制、语音输入与朗读。自动生成会话标题不用于本项目：每个窗口以用户设置的角色名字命名。独立 OCR 已由现有图片/文档输入覆盖日常阅读场景；代码补全、任意自定义工具和批处理接口不属于此间的陪伴聊天操作。

## 验证情况

- 24 项自动测试：日期跨日与时区、工具流式事件、来源安全、历史回传、角色隔离、失败响应、语音协议及已有聊天/记忆/附件逻辑。
- DeepSeek 真实调用：日期回答、网页搜索、阅读链接及后续追问、短文本语音合成与转写均通过。
- 1280px 桌面、390px 手机宽度的节点复用、流式输出、记忆通知、滚动保持、停止重试与角色切换回归通过。
- Windows 独立 EXE 已验证启动、内嵌资源、模拟聊天、端口回退、重复启动和重启数据保留。
- Android 共用运行时与 SQLite/网络桥回归通过，APK 构建及签名验证通过，新旧签名一致。没有连接安卓真机，麦克风权限与扬声器播放仍需在实际手机上体验验证。
